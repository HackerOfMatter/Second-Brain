## Behaviors
1. **Telling.** This style reflects high task/low relationship behavior (S1). The leader provides clear instructions and specific direction.
2. **Selling.** This style reflects high task/high relationship behavior (S2). Build trust and confidence
3. **Participating.** This style reflects high relationship/low task behavior (S3). Help them function independently to finish task
4. **Delegating.** This style reflects low relationship/low task behavior (S4). Fully independent for the task
