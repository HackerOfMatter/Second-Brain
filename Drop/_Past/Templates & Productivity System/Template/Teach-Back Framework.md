# Teach-Back: Bankruptcy — Core Concepts

## 1) Explain like I’m teaching a friend (simple)
Bankruptcy is a legal reset that stops collection (automatic stay), gathers the debtor’s property into an estate, and pays creditors fairly by rules. Some cases liquidate assets (Ch7); others reorganize debt so the debtor can keep operating and pay over time (Ch11/13). In the end, many debts are wiped out (discharge), but not all.

## 2) Example/analogy
- **Traffic light analogy**: Filing is a red light (automatic stay) for creditors; a court cop (trustee or judge) directs traffic so everyone takes turns by priority. In Ch11/13 the light cycles so traffic flows again (reorganization/plan).

## 3) Common misconceptions → corrections
- “Bankruptcy erases everything.” → Many debts are **nondischargeable** (DSO, certain taxes, fraud).
- “Company always shuts down.” → **Ch11** often keeps it alive under a plan.
