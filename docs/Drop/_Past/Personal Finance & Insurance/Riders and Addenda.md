# 🧠 Core Idea

> ⚡ **In essence:** Riders and addenda are supplemental agreements that modify or expand the main contract without rewriting it entirely.

# 🔍 Key Concepts

- **Definition(s):**
    
    - **Rider** — an additional document that alters specific provisions of the contract.
        
    - **Addendum** — a formal attachment that adds terms to an existing contract.
        
- **Principles:**
    
    - Must be **mutually agreed upon** and **in writing**.
        
    - Often used to tailor standard forms (e.g., lease addenda).
        
    - Legally binding as long as they don’t contradict the main agreement unless explicitly stated.
        
- **Example:**
    
    - An employment contract rider adds new confidentiality obligations after the initial signing.
