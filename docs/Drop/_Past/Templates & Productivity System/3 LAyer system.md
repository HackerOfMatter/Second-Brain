# Pre-Class Primer
Goal: activate prior knowledge and curiosity, not memorize.  
Before class (10–15 min max):

He skims the chapter headings or slides and writes 3-4 **questions he wants answered**.  
This makes him alert for those answers during class — keeping him attentive rather than sleepy.
## Key Questions
- What do I already know about this topic?
- What do I expect to learn?
- Why might it matter?

### ✍️ Layer 2 — _During Class (Structured Capture)_

Goal: record **concept skeletons** and **example triggers**, not every word.

In Obsidian or on paper:

# Class Skeleton
Main Idea → Supporting Idea → Example

🔹 Distribution Channels
   → Definition (intermediaries that move product)
   → Why needed: reach, efficiency
   → Ex: Amazon logistics

⭐ Prof's emphasis: Channel conflict (test?)

Trent only notes:

- Headings / bolded terms
    
- Professor’s tone emphasis (“this will be on exam”)
    
- Real-world examples
    
- Questions he still has
    

💡 Tag unclear ideas immediately with `??` so he can fill them in later.


### 🧩 Layer 3 — _Post-Class Processing (Teach-Back Mode)_

Within 24 hrs, open the same note and complete:

# 🧠 Teach-Back Summary
> “If I were teaching this, I’d explain it like this…”

1. Restate in your own words  
2. Add examples (real or imagined)  
3. Connect to previous topics  
4. Add “HW Corner” for formulas or definitions

## 🗂️ 4. Organizing Menial vs. Deep Notes

|Folder|Purpose|Content|
|---|---|---|
|`/Homework Notes/`|Fast lookup|Definitions, formulas, example problems|
|`/Concept Notes/`|Teach-ready|Summaries, analogies, connections|
|`/Class Capture/`|Raw data|Skeleton notes during lectures|

Trent only refines `/Class Capture/` notes that truly matter (saves time).

## 🔁 5. Weekly System (Example)

|Day|Focus|Action|
|---|---|---|
|Mon|Pre-Class Preview|Write 3 questions|
|Tue|Lecture|Skeleton capture|
|Wed|Post-Class|Fill Teach-Back section|
|Thu|Compare w/ other class|Link ideas|
|Fri|Weekly review|Teach one concept aloud|
