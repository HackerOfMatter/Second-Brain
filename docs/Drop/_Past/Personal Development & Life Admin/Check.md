# 🧠 Core Idea

> ⚡ **In essence:** A check is a written order directing a bank (drawee) to pay a specific amount from the drawer’s account to a payee.

# 🔍 Key Concepts

- **Definition(s):**
    
    - **Check** — a three-party negotiable instrument: _drawer_, _drawee (bank)_, and _payee_.
        
- **Principles:**
    
    - Payable on demand.
        
    - Transfers via **indorsement and delivery**.
        
    - May be certified or cashier’s checks for guaranteed payment.
