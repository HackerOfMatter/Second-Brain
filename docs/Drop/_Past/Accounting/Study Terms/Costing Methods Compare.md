## Rising 📈

| Method           | COGS (Expense) | Ending Inventory (Asset) | Net Income | Why                                             | Tax Impact      |
| ---------------- | -------------- | ------------------------ | ---------- | ----------------------------------------------- | --------------- |
| **FIFO**         | 🔽 Lower       | 🔼 Higher                | 🔼 Higher  | Sells Old/cheap leaving newer (Expensive) left  | 🔼 Higher taxes |
| **LIFO**         | 🔼 Higher      | 🔽 Lower                 | 🔽 Lower   | Sells new (expensive) first leaving old/cheaper | 🔽 Lower taxes  |
| **Weighted Avg** | Medium         | Medium                   | Medium     |                                                 | Medium          |

## 📉 When Prices Are Falling 📉
	
| Method           | COGS (Expense) | Ending Inventory (Asset) | Net Income | Tax Impact      |
| ---------------- | -------------- | ------------------------ | ---------- | --------------- |
| **FIFO**         | 🔼 Higher      | 🔽 Lower                 | 🔽 Lower   | 🔽 Lower taxes  |
| **LIFO**         | 🔽 Lower       | 🔼 Higher                | 🔼 Higher  | 🔼 Higher taxes |
| **Weighted Avg** | Medium         | Medium                   | Medium     | Medium          |
|                  |                |                          |            |                 |
|                  |                |                          |            |                 |

## Summary

| Method           | Skews Toward...            | When     | Why                                          |     |
| ---------------- | -------------------------- | -------- | -------------------------------------------- | --- |
| **FIFO**         | ✅ Higher income and assets | Prices ↑ | Older, cheaper costs make profit look higher |     |
| **LIFO**         | ✅ Lower income and taxes   | Prices ↑ | Newer, higher costs raise expenses           |     |
| **Weighted Avg** | Neutral, smoother results  | All      | Blends all costs into one average            |     |
